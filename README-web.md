# subs-editor Web App

轻量本地网页工具，用于从 CSV 生成台词本 TXT 和按集拆分的 SRT ZIP。  
它不替代原有命令行流程，只是给“生成台词本 / SRT”这一步加一个更方便的界面。

---

## 启动

在项目目录运行：

```bash
python web_app.py
```

打开：

```text
http://127.0.0.1:7860/
```

> 如果 7860 端口被占用，先停止旧的 `python web_app.py` 进程后再启动。

---

## 输入 CSV

可以从本地任意位置上传 CSV，不要求放在 `input-csv/`。

CSV 默认识别 5 列：

```text
编号 / 时间戳 / 台词 / 角色 / 集数
```

支持有表头或无表头：

- 有表头：按列名读取
- 无表头：按前 5 列顺序读取

上传 CSV 后，“输出名称”会自动填入文件名去掉 `.csv` 的部分，也可以手动修改。

---

## 基础设置

**集数筛选**

留空表示全部集数。支持：

```text
11-15
EP11,EP12
11 12 13
```

**只处理角色非空行**

默认开启。适合从 Excel/Numbers 里框选已标注范围另存 CSV 后生成。

**主角 marker**

用空格或逗号分隔，例如：

```text
q e
```

这些 marker 会被视为主角，台词本和 SRT 中使用主角格式。

---

## 高级设置

**台词本：主角前缀**

默认：

```text
- 
```

**台词本：其他角色前缀模板**

默认：

```text
【{role}】
```

`{role}` 会替换为 CSV 的角色 marker。

**台词本：连续台词连接符**

默认是空格。只用于同角色、连续编号的台词合并。

**台词本：n/9 切换分隔符**

默认：

```text
❖
```

当新段落的角色 marker 以 `n` 或 `9` 开头时，会在它和上一句之间插入：

```text

❖
```

同时，台词本显示角色时会去掉开头的 `n` 或 `9`：

```text
n甲 -> 【甲】
9b  -> 【b】
nq  -> 主角格式
```

这个规则只影响台词本，SRT 不插入分隔符。

**台词本：每集标题模板**

默认：

```text
{ep}
```

可用变量：

- `{episode}`：完整集数，如 `EP11`
- `{ep}`：后两位，如 `11`

**台词本：清理每句台词内部空格**

默认开启。开启后，每句台词内部的空格会先被清理，再用“连续台词连接符”合并上下句。

---

## SRT 输出规则

SRT 固定按同角色、连续编号合并。

- 连续台词连接符固定为空格
- 主角前缀默认留空
- 其他角色前缀默认 `【{role}】`
- 不插入台词本里的 `❖` 分隔符
- 保留原始角色 marker，例如 `n甲` 在 SRT 里仍显示为 `【n甲】`

---

## 输出和下载

点击“生成 TXT / SRT”后：

- 页面会显示完整台词本预览
- “下载台词本 TXT”下载 `.txt`
- “下载 SRT ZIP”下载按集拆分的 `.srt` 压缩包

生成结果不会自动保存到项目目录；需要用下载按钮手动保存。  
在普通浏览器中下载会进入浏览器默认下载目录，通常是 `Downloads`。
